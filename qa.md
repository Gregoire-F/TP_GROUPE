## Expliciter la procédure pas à pas pour installer un WebGUI sur votre LLM local ##

- Installer Docker sur la machine
- Création d'un fichier docker compose.yml avec les réglages depuis le github Ollama
- Commande sudo docker compose pull
- Lancer la commande docker qui lance le web GUI
- Aller sur l'adresse IP locale qui fournit l'interface pour interargir avec le modèle IA
